The sensor has an optional I2C timeout, which resets the bus if either the SCL or SDA signal line is low for ≥ 51 ms. It is recommended that the I²C
interface is operated at speeds exceeding 100 kHz to ensure timely reading of the data for low latency sensor output processing. Latency is
calculated as INTRSAMPLES x (WAIT + 1) ms at ULP mode.

I2C bus signals (SDA and SCL) are open-drain and require external pull-up resistors per I²C specification. This is typically done with a 2 kΩ pull-up
resistors (or greater for lower power operation). Series resistors in the signal path are optional to protect the sensor input architecture from high-
voltage spikes on the bus lines, minimize crosstalk, and undershoot events of the bus signals. The supply voltage to the sensor should be less than
or equal to the pull-up voltage for the I2C and INTB.

The I2C controller initiates all data transfer and generates the SCL clock signal. The sensor responds as a target device, supporting bidirectional

Interrupt System


The INTB output enables autonomous sensor operation with minimal host intervention. The interrupt system supports flexible triggering conditions,
debounce filtering, and configurable signal polarity to accommodate various interrupt controller architectures.

Interrupt Signal and Operation

Interrupt output is open-drain and requires external pull-up resistor (10 kΩ or greater for low-power operation) to VDD. Interrupt polarity is
configurable via INTRPOL register (0x09[3]). Default is active-low.

Interrupt Modes

The sensor has configurable interrupt modes (register addresses 0x0C-0x0E and 0x16-0x17), allowing different trigger conditions.
Interrupt is generated when the sensor measurement exceeds the programmed threshold set by INTRTHR registers (0x0C-0x0D) for a specified
number of consecutive samples set by INTRMODE and INTRSAMPLES.

Standard Mode (BTNMODE = 0):
INTB can be configured to either output 100 µs pulses (INTRPERSIST=0) for as long as the signal is above the threshold level or a constant level
(INTRPERSIST=1) until the interrupt status register (0x02) or register 0x01 is read by controller.

Button Mode (BTNMODE = 1 and INTRMODE=0):
Implements press-and-release detection with separate rising set by INTRTHR registers (0x0C-0x0D) and falling thresholds set by FALLTRTHR
registers (0x16-0x17), providing hysteresis for stable button emulation.

Hardware Programmable Interrupt Threshold

The sensor implements autonomous interrupt threshold configuration through an external resistor between THR_ADR pin and VDD or GND. This
dual-function pin configures both the sensor I²C address and the sensor interrupt threshold (0x0C-0x0D) during power-on reset. The interrupt

12-Bit and 16-Bit Modes



The sensor has two data output types selected by the ENFILTER register: Ultra-Low Power mode (ULP mode) and High-Performance mode (HP
mode).

In ULP mode (ENFILTER = 0), the sensor output is 12-bit 2’s complement which can be read from ADCOUT[15:4]. The data rate is determined by the
WAIT register. Data is updated every “WAIT + 1ms”.

In HP mode (ENFILTER = 1), the sensor output is 16-bit 2’s complement which can be read from ADCOUT[15:0]. In this mode, there are two settings
selected by HIGHORDER register. When HIGHORDER = 0, the device is set to 4-point sum. The data is updated every “WAIT + 4ms”. When
HIGHORDER = 1, the device is set to 16-point sum. The data is updated every “WAIT + 16ms”.

States and Modes of Operation


The sensor implements a state machine architecture with two primary operating modes—Active Mode and Shutdown Mode—optimized for ultra-
low-power operation in battery-powered and Always-On applications.





Shutdown Mode

Shutdown mode provides maximum power savings by completely disabling the analog front-end while retaining digital register contents (except
PRELDADJ register) and I²C interface responsiveness, allowing the host to read configuration or initiate return to Active Mode via register write.

In this mode, PRELDADJ changes back to POR value when AUTOPRELDADJ is on. If AUTOPRELDADJ is off the value of PRELDADJ will be the last
manually-written-in value or the POR, if it is never manually written.

To enter shutdown mode from active mode, disable sensor by writing a “0” to EN register.
When exiting shutdown mode (setting EN from 0 to 1), clear the INTREN and BTNMODE bits. Set both bits to zero before enabling the AFE. If
needed, re-enable these bits no earlier than Δt = 3 * (WAIT + PRECHARGE + 1) after setting EN to 1.

Active Mode

In active mode, the sensor performs periodic ADC conversions at specified intervals: WAIT+1 ms for ULP mode, WAIT+4 ms for 4-order HP mode
WAIT+16 ms for 16-order HP mode. Between conversions, the analog front-end enters a standby state where all analog circuitry powers down
while retaining digital register contents and I²C interface responsiveness.

Baselined Data Output (ADCRAW=0, Default)
This mode implements automatic baseline tracking with continuous offset correction, suitable for applications requiring long-term stability,
autonomous interrupt generation, and minimal host intervention.

In this mode, the output represents instantaneous force magnitude relative to a dynamically updated zero-force reference point (baseline):
ADCOUT = Raw_ADC – BASELINE (in two's complement).
AUTOCAL and INTRTHR thresholds are referenced to current BASELINE value. Interrupt and auto-calibration threshold values shall be positive and
interrupt threshold shall be higher than auto-calibration threshold value.

When the sensor signal is less than the AUTOCAL threshold, the baseline is updated at a rate specified by CALPERIOD and weight specified by
RISEBLWGT and FALLBLWGT.
When the sensor signal exceeds the auto-calibration threshold, the baseline is updated at a rate specified by CALRESET and weight specified by
RESETWGT. There is also an optional negative-side threshold (enabled with ENNEGZONE and specified by NEGTHSEL as a fraction of the AUTOCAL
threshold), below which the baseline is only updated after a NEGRESET timeout, again using RESETWGT to calculate the new baseline. The auto-
calibration and interrupt levels are referenced to the baseline value; therefore, baseline updates automatically change the stated thresholds. When
the interrupt threshold is exceeded for the number of samples set by the INTRSAMPLES register (0x0E), an interrupt is asserted.

When the sensor signal is higher than the interrupt threshold, no auto-calibration is performed unless ENCALMODE is enabled. Once sensor
measurements drop below the auto-calibration threshold, the auto-calibration routine is re-enabled after a one-time delay defined by the
LIFTDELAY register (0x0A).

Raw Data Output (ADCRAW=1)
Raw mode disables automatic baseline tracking and automatic offset correction, providing unprocessed ADC data for applications requiring custom
signal processing algorithms or where baseline subtraction is performed in host software. This mode is essential for advanced filtering techniques.

In this mode, BASELINE = 0 and ADCOUT = Raw ADC Value (in two's complement). Output reflects absolute sensor capacitance with electrical offset
and mechanical preload included. AUTOCAL and INTRTHR thresholds become absolute thresholds (not baseline-referenced). To make preload
adjustments manually, AUTOPRELDADJ should be disabled (set to 0) and then adjustments made through PRELDADJ register.

Electrical Design, Layout, Placement, Handling and Package Information

Electrical Design and Board Layout Considerations
    •   Two bypass capacitors are required, 2.2 µF & 1 nF, to reduce noise on the power supply. Use higher value bypass capacitors for noisy
        power supplies. Ensure that both capacitors are placed close to the sensor – REQUIRED.
    •   Symmetrical routing improves sensor self-alignment during assembly – REQUIRED.
    •    Place the nearest components at least 0.3 mm (RECOMMENDED) away from the sensor.
    •   Do not use vias directly under the sensor solder balls.
    •   Keep signal lines short (REQUIRED) and free of 90° turns (steep angles/corners can cause undesired acid traps during the manufacturing
          process). Use 45° turns or rounded-edge-turns for all signal/power lines.
    •   Do not use glue/epoxy between sensor and board or around the sensor – REQUIRED.
    •   The sensor edge should be at least 0.25 mm from all edges of the PCB – RECOMMENDED.
    •      If using a flexible PCB, a top hatched ground plane is recommended.
    •    Underfill is not recommended. For harsh environments like salt spray please contact Semtech for recommendations for materials for
           under-fill and glob top.
    •   For additional stability consider implementing “teardrop” routing into vias, pin pads and T-junctions; this increases the copper area and
         avoids steep angles in areas where multiple traces meet in a common point.
    •   Power the AFE from a dedicated on-board low-noise LDO regulator to minimize supply-induced noise coupling.
    •   Make the traces to all the pins the same width. Semtech recommends greater than (or equal) 6 mils traces for all signals except the traces
           directly connected to bumps of the sensor. These should be 4 mil traces for better reflow results.

Nozzle Considerations


SMT assembly machines typically employ a vacuum nozzle for Pick & Place (P&P) operations. Not all equipment is the same, but there are some
general guidelines to follow, for optimal performance/yield.
    •    Select a vacuum nozzle only.
       o  DO NOT use mechanical grippers or collets that contact the edges/sides of a WLCSP.
       o  DO NOT handle WLCSP parts with metal tweezers.
    •    Select softer nozzle materials where possible.
       o   Nozzle materials can vary (metal, ceramic, plastic, rubber), and certain equipment requires certain nozzle materials. Select softer
              material to avoid potential damage from mechanical shocks.
    •    Select an appropriate nozzle tip shape.
       o   Nozzle tip shape can affect the amount of pressure applied to a single point on a WLCSP part.
       o   Nozzle tips should be circular, square/rectangular, and preferably with a vertical separator.
       o   The nozzle tip surface should be a single plane; do not use a nozzle with a protruded edge.





                                                 Acceptable Vs NOT acceptable Tip Shapes

    •    Select an appropriate nozzle tip size, for the part being placed.
       o   The largest tip dimension should be smaller than the size of the WLCSP part.
       o   The tip should account for the tolerance of the pick accuracy, so that it’s not possible for the nozzle tip to contact the edge or the
              corner of a part.
       o   The tip size should be as large as possible, while satisfying the above 2 points.

Pick and Place Operation


The P&P operation consists of two key steps: picking a part out of the carrier tape pocket, and placement of that part onto a circuit board. Both
operations are performed with some alignment tolerance: nozzle-to-part tolerance during the pick, and part-to-board alignment during the
placement. Additionally, the placement should occur with as little force as possible, to press the die into place on the board.

WLCSP parts are shipped to customers in standard carrier tape & reel packaging. Parts sit in a pocket that is slightly larger than the size of the part.
A part can move laterally inside the pocket, typically by less than 0.1 mm, but this varies by product.
    •      If available, the P&P equipment should use a vision detection system to align the P&P nozzle to the center of the die, for every part
          picked.
    •      If a vision alignment system isn’t available, the nozzle size selection should account for the positional tolerance of the WLCSP part in the
           carrier tape pocket.

Assembly Instructions
