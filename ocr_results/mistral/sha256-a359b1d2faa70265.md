## Double-Ended Beam Load Cell

### FEATURES

- Capacities: 25k to 125k lbs
- Environmental protection: IP67 (DIN 40.050)
- Material: Nickel-plated steel
- Certified to NTEP class IIIL, 10000 divisions
- **Optional**
  - FM approved for use in potentially explosive atmosphere



### APPLICATIONS

- Weighbridges
- Silos, tanks and hoppers

### DESCRIPTION

The Model 5303 is a link loaded mid to high capacity, nickel-plated alloy steel double-ended shear beam type load cell.

This product is designed for use in certified truck and rail scales and is available in capacities from 25k to 125k lbs.

This load cell is rated intrinsically safe by the FM system, making it suitable for use in potentially explosive atmospheres.

This load cell is certified for trade applications by American NTEP standards.
