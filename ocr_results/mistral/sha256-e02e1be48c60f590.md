# Single Point Load Cell BEF-F with a Rated Load of 3 ... 5 kg

Data sheet



Performance Features

- Aluminum single point load cell
- Accuracy class: 0.1 %
- Designed for platforms of maximum dimensions 150 mm x 150 mm (off-center load compensate)
- Compact and easy to install
- Ideally suited for low cost weighing and force measurement applications

Application

- Food industry
- Coal and steel industry
- Chemical / pharmaceutical industry
- Waste management / recycling
- Packaging technology
