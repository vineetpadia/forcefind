## Rocker Column Load Cell

### FEATURES

- Capacities: 30T and 40T
- Self-restoring rocker column
- High performance compact design
- Environmentally sealed, IP66/IP68 (5 bar)
- Certificate: OIML R60 (NTEP Class IIIL: 10,000d Pending)
- Current calibration output ensures easy and accurate parallel connection of multiple load cells
- Anti-rotation pin



### APPLICATIONS

- Weighbridges
- Silo and hopper weighing
- Process weighing

### DESCRIPTION

The Model 116 is a high-capacity single-column load cell, designed around a nickel-plated, alloy steel element. It is environmentally sealed and the use of redundant O-rings and high-grade potting material provide excellent ingress protection.

The Model 116 is suitable for all heavy weighing applications and provides the user with excellent overall value.
