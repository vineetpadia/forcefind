# Aluminum High Capacity Single-Point Load Cell

FEATURES

- Capacities 100–250 kg
- Aluminum construction
- Single-point 400 x 400 mm platform
- IP66 protection
- Available with metric threads



APPLICATIONS

- Large platform scales
- Hanging scales
- Check weighing

DESCRIPTION

The Model 1262 is a high performance, high capacity single- point load cell designed for direct mounting of large weighing platforms.
