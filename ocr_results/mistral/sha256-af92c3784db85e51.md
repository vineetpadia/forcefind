# 3110-3115

# HEAVY COMPRESSION LOAD CELLS (VERY HIGH CAPACITIES)

High-capacity compression load cells.

Model 3115 - 3 MN



# Features

- o Wide range of capacities: 30 kN (3 t) up to 50 MN (5.000 t)
- o Material: nickel-plated steel (3115) or stainless steel (3110)
- o Protection class: IP65
- o A whole range of mounting accessories is available
- o Cable length: see drawing table - CL (other lengths available on request)
- o Also available as standard reference load cells according to ISO 376 (classes 1, 0,5 and 00 - see specific data sheet 3115-ISO)

# Most popular options

Application(s) SENSY's load cells 3110-3115 are perfectly designed for the following applications:

- Industrial force measurement, industrial process control (ISO 9000, ...),
- Primary transducer for universal testing machine, structure weighing.
