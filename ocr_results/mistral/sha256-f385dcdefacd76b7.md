## Single-Ended Beam Load Cell

### FEATURES

- Capacities: 200–2500 lbs.
- Low profile, stainless steel construction
- Hermetically sealed, IP66 and IP68
- Certified to OIML R-60, 5000d and NTEP class III, 5000 divisions
- Current calibration output (SC version) ensures easy and accurate parallel connection of multiple load cells
- Interchangeable with existing Model 5102
- **Optional**
  - ATEX and FM certified versions are available for use in potentially explosive atmospheres



### APPLICATIONS

- Platform scales
- Belt scales
- Silo/hopper weighing
- Overhead track scales

### DESCRIPTION

The Model 9102 is a stainless steel single-ended beam type load cell.

This product is suitable for small and medium platform scales, overhead track scales and process weighing.

The fully welded construction and water block cable entry ensure that this product can be used successfully in demanding environments found in the food, chemical and allied process industries.
