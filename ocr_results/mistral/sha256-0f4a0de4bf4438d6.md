# SB5 CAN beam load cell



## product description

The SB5 CAN is a high-accuracy, low-profile bending beam load cell, featuring a unique blind-hole load introduction that ensures optimal force transmission and improved stability in weighing applications. It is particularly suited for industrial platform scales, pallet truck scales, and vessel and tank weighing systems. Its stainless steel construction and environmental sealing to IP67 make it a robust choice for industrial applications where a full hermetic seal is not required.

An embedded CAN board transforms the SB5 into a fully digital load cell, enabling direct CAN communication without requiring external signal converters. This ensures seamless integration into modern weighing and control systems.

The SB5 CAN is fully interchangeable with the SB4 CAN and is available in a range of capacities.

Setup is straightforward and can be performed with a terminal emulation program or the Flintec FDC application, available from flintec.com.

## applications

Industrial platform scales, pallet truck scales, vessel and tank weighing systems.

## wiring

The load cell is provided with a shielded, 4 conductor cable (AWG 24).

Cable jacket: polyurethane

Cable length:

3m for SB5-5 kN/10 kN/20 kN

4.5m for SB5-50 kN/100 kN

Cable diameter: 5mm

The shield is floating

(On request the shield can be connected to the load cell body)
