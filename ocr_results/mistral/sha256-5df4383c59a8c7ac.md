# TLC

# ANALOG WEIGHT TRANSMITTER

LAUMAS®



# DESCRIPTION

- Analog weight transmitter.
- Dimensions: 45x26x11 mm; 1 fixing hole Ø4 mm.
- IP67 box in ABS or polycarbonate (on request).

# INPUTS/OUTPUTS AND COMMUNICATION

- Current or voltage analog output.
- 1 load cell dedicated input.

# MAIN FUNCTIONS

- Connections to:
  - PLC via analog output.
  - up to 4 load cells in parallel by junction box.
- Compatible with analog/digital boards normally installed on PLC.
- Calibration with sample weights or load cell simulator.
- Ideal for use with tension/compression load cells.

IP67 BOX IN ABS OR POLYCARBONATE (on request)
