# Miniature Compression Force Sensor K-1613
with Rated Force from 0.1 ... 50 kN





Performance Features

- Miniature sensor for compression force
- TEDS (Transducer Electronic Data Sheet)
  Standard IEEE 1451.4 (optional)
- Simple handling and assembly
- Stainless steel
- Level of protection IP65
- Long-term stability
- Special versions on request

Application

- Equipment engineering
- Fully automated machining centres
- Measuring and control devices
- Materials testing machines
- Tool engineering
- Special mechanical engineering
