# Compression Load Cell

FEATURES

- Capacities: 50k to 200k lbs
- Certified to NTEP class IIIL, 10000 divisions
- Environmental protection: IP68 (DIN 40.050)
- Material: Stainless Steel
- Hermetically sealed—IP68
- Optional
  - FM approved for use in potentially explosive atmospheres



APPLICATIONS

- Silo, tanks and hoppers
- Suspended silos, tank and hoppers
- Railroad scales
- Weighbridges

DESCRIPTION

The 792 canister is designed for compression applications. Its stainless-steel construction combined with hermetic sealing allows the 792 to be used in harsh environments.

The 792 is built for heavy capacity weighing applications where accuracy and reliability are required over long periods of time.

Hermetic sealing offers excellent protection from moisture and provides long-term stability and reliability.
