# RIP6100N
## REMOTE DISPLAY

LAUMAS®



# DESCRIPTION

- Remote display with big digits display, suitable for wall mounting.
- 6-digit semi-alphanumeric red SMD LED display (90 mm height).
- 4 signalling LED.
- Aluminum profile box.
- IP30 protection rating.
- Serial ports for transmission protocol.
- Configuration from PC via RS232 serial port.
- 15 settable addresses.
- Power supply included: 12 VDC/2 A - 100÷240 VAC input cable length: 1.2 m.
- Serial connection cable (length: 5 m) and brackets for wall mounting included.
