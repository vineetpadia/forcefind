# Single Point Load Cell AB with a Rated Load of 50 ... 500 kg



# Performance Features

- Aluminum single point load cell
- 5000d OIML R60 and 5000d NTEP approved
- Level of protection IP65
- 6-wire configuration
- Designed for platforms of maximum dimensions 800 mm x 800 mm (off-center load compensated)
- ATEX 2014/34/EU version for hazardous area (option)

# Application

- Food industry
- Coal and steel industry
- Chemical/pharmaceutical industry
- Waste management/recycling
- Packaging technology
