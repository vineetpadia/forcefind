# Rocker Pin Load Cell CB50X-DL with a Rated Load of 20 ... 60 t



Performance Features

- Digital rocker pin load cell made of stainless steel, welded with protection class IP68
- 4000d OIML approved, optional Version C5 with 5000 OIML on request
- Digital output via RS485 interface
- Spherical and self centering base
- Anti-rotating system included
- Ideally suited for weighbridge use and silo weighing
- Rodent protection as standard
- Integrated ESD protection
- Lightning protection integrated to DLCJB box

Application

- Food industry
- Coal and steel industry
- Chemical / pharmaceutical industry
- Waste management / recycling
- Packaging technology
