# MOUNTING AND LOAD APPLICATION

The load cells are fixed at the mounting bores. For the recommended screws and tightening torques refer to the table below:

|  Max. capacity | Thread | Min. property class | Tightening torque^{1)}  |
| --- | --- | --- | --- |
|  1.5...40 kg | M6 | 8.8 | 10 N·m  |

1) Recommended value for the stated property class. For screw dimensioning please refer to the appropriate information given by the screw manufacturers.

Load must not be applied to the side where the cable connection is located, as this would cause a force shunt.
