# MODEL 190
15kg ... 400kg





- Double bending beam load cell
- Versions:
  - 190a (50...400kg): Nickel-plated Alloy Steel Silicone sealing, IP 66 (EN 60529), 4000 divisions OIML R60 class C
  - 190i (15...400kg): Fully Stainless Steel construction Hermetically sealed, fully welded, IP 68 (EN 60529) and IP 69K (ISO 20653), 3000 div. OIML R60 class C
- High accuracy with off-center loads
- Available in ATEX® version (optional) Zone 0-1-2 (gas) and 20-21-22 (dust)
- Applications: direct platforms up to 600 x 600 mm or 800 x 800 mm; filling scales
- Doppelbiegebalkenprinzip
- Ausführungen:
  - 190a (50...400kg): Vernickelter Stahl, vergossen, IP 66 (EN 60529), 4000 Teile OIML R60 Klasse C
  - 190i (15...400kg): Edelstahl, hermetisch dicht, verschweißt, IP 68 (EN 60529) und IP 69K (ISO 20653), 3000 Teile OIML R60 Klasse C
- Hohe Genauigkeit bei exzentrischer Lasteinleitung
- Erhältlich in ATEX® -Ausführung (optional) Zone 0-1-2 (Gas) und 20-21-22 (Staub)
- Anwendungen: Plattformwaagen mit nur 1 Wägezelle, 600 x 600 mm oder 800 x 800 mm; Behälterwaagen
