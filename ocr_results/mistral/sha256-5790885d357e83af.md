# 5200-5205

# TENSION LINK LOAD CELLS

Tension link load cells specially adapted for standard shackles.

Model 5205 - 25 kN



# Features

- o Sturdy design
- o Protection class: IP66
- o Cable length: see drawing table - CL (other lengths available on request)
- o Material: stainless steel (5200), nickel-plated steel (5205)

# Most popular options

Application(s) SENSY's load cells 5200-5205 are perfectly designed for the following applications:

- Tension force measurement,
- Suspended industrial weighing,
- Winch monitoring.
