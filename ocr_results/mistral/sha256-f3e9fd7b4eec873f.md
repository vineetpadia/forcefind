# Compression load cell RH10X with a Rated Load of 100 ... 1000 t

Data sheet



# Performance Features

- Compression load cell made of stainless steel, welded with protection class IP68
- Accuracy up to ±0.2 %
- Spherical load button for perfect alignment of the load
- Low profile design
- Ideally suited for any industrial weighing and level control application
- ATEX 2014/34/EU version for hazardous area (option)

# Application

- Food industry
- Coal and steel industry
- Chemical / pharmaceutical industry
- Waste management / recycling
- Packaging technology
