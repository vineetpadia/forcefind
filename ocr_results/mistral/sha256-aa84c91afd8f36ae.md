# MODWF

WiFi / SERIAL TRANSCEIVER

LAUMAS®

MODBUS RTU

DESCRIPTION

- WiFi communication interface device between two serial devices.
- Transceiver in IP67 polycarbonate box with 2 M16x1.5 cable glands.
- Dimensions: 80x170x65 mm (four fixing holes Ø4 mm; centre distance: 60x120 mm).
- Backlit alphanumeric LCD display, two-line by 8-digit (5 mm height), visible area: 38x16 mm.
- 6 signalling LED.
- 4-key keyboard.

INPUTS/OUTPUTS AND COMMUNICATION

- WiFi module for wireless connection with ModBus RTU, ASCII Laumas protocols.
- RS485/RS232 serial ports for communication via protocols ModBus RTU, ASCII Laumas or continuous one way transmission.

MAIN FUNCTIONS

- Connections to:
  - PC via WiFi/virtual Ethernet port;
  - PC/PLC via RS485/RS232 (up to 99 instruments with line repeaters, up to 32 without line repeaters);
  - others MODWF devices and W series weight indicators equipped with optional module WiFi.
- WiFi/serial tunnel function.
- Communication with existing WiFi networks.
- Energy saving mode.



CERTIFICATIONS

- **ERC** Complies with the Eurasian Custom Union regulations
- **UK** Equivalent of the CE marking for the United Kingdom
